## 4. 사업 범위

| ID | 구분 | 항목 | 비고 |
|----|------|------|------|
| SCP-01 | In-scope | 회의실 조회·예약·취소 기능 (추정 — 확인 필요) | 프로젝트명 기반 추정 |
| SCP-02 | In-scope | 회의실·예약 현황 관리 기능 (추정 — 확인 필요) | 프로젝트명 기반 추정 |
| SCP-03 | Out-of-scope | 제외 항목 미확인 — 확인 필요 | 킥오프(3-AN-02)에서 경계 확인 |

> 항목마다 `SCP-` 식별자를 붙인다. 수행계획서(`2-MG-01-O1` §3)·WBS 커버리지 표(`2-MG-02-O1` §5)·요구사항 정의서(`3-AN-08-O1`)가 이 ID로 범위를 잇는다. 한 번 부여한 ID는 바꾸지 않는다. **착수 뒤 범위가 바뀌면 이 표를 고치지 않는다** — 변경 요청(`CR-`)으로 처리하며, 확정된 `CR-`이 이 표와 함께 범위 근거다(게이트 pn-01.P1·P9).

> 착수 뒤 범위 변경: 변경 요청 대장(`2-MG-03-O2`) — 확정된 `CR-`이 이 표와 함께 범위 근거다.
