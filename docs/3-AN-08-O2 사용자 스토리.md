## 2. 사용자 스토리 목록

> **출처 질문 칸의 값.** 인터뷰에서 실제로 던진 질문의 `Q-` ID가 기본이다. 인터뷰 종료 후 사용자 인터뷰(`3-AN-08`)의 「인터뷰 뒤 추가 요구사항 — 변경관리 대체경로」로 추가된 스토리는 대응하는 `Q-`가 없으므로 **`변경관리 대체경로(인터뷰 미실시) — PM 승인 <이름·일자>`**로 적는다(품질 게이트 an-08.P1 예외). 인터뷰 자체를 수행할 수 없어 발주처 서면 답변이나 결정을 출처로 쓰는 경우(`3-AN-08` 「인터뷰를 수행할 수 없는 경로」, 발주처 확인 규약(`9-CM-06`))는 서면이면 `서면: <문서>§n`, 결정이면 `D-`(킥오프 `D-nn`·정기 회의 `D-{회의번호3}.{n}`)를 적는다. 던지지 않은 질문의 `Q-`를 지어내지 않는다. 하류는 이 칸이 `Q-`로 시작하면 질문 추적, 「변경관리」로 시작하면 변경 이력을, `서면:`·`D-`로 시작하면 그 출처 문서·결정을 따라간다.
>
> **수용 기준**은 스토리마다 2개 이상, 각각 결과를 확인할 수 있는 문장으로 쓴다(an-08.P5). 시스템 테스트(`6-TS-13`) 케이스의 기대 결과 원천이며, **번호가 곧 인용 ID다** — 하류는 `US-01.1`·`US-01.2`로 인용하므로(`6-TS-13-O1` §4 근거 열) 한 번 매긴 순서를 바꾸지 않는다. 기준을 더할 때는 뒤에 붙인다.
