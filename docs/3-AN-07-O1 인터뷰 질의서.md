## 5. 추적성 안내

각 응답은 사용자 인터뷰(`3-AN-08`) 단계에서 다음 ID로 변환된다. 식별자 형식은 사용자 인터뷰(`3-AN-08`)의 규칙을 따른다. `참조` 열은 이 질문의 근거(`AS-`·`WK-`·`INS-`·`TERM-`·`ENT-`·`REL-`·`BR-`·`STK-`·`SCP-`·`P-`·`RSK-`)이며 비워 두지 않는다(품질 게이트 an-07.B1).
- `Q-XXX-NN` → `US-[순번]` (사용자 스토리, 예: `US-01`)
- `Q-XXX-NN` → `REQ-[구분]-[순번]` (요구사항, 예: `REQ-F-001`)
