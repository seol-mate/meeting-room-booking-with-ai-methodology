## 6. 표기 규칙

| 항목 | 규칙 |
|------|------|
| 이름 | 실명 확인 불가 시 "역할 + 소속" 조합으로 기재한다 (예: `총무팀 담당자`). 공란 금지 |
| 영향력·관심도 | `매우 높음` / `높음` / `중간` / `낮음` 중 하나 |
| ID | `STK-01`부터 순번. 킥오프 회의록·인터뷰 질의서·요구사항 정의서가 이 ID로 참조한다 |
| 인터뷰 필요 | `필요` / `불필요` 중 하나. 전 항목 필수 기재(품질 게이트 an-01.P3) |
| 승인 권한 | `있음` / `없음`. 범위가 한정되면 괄호로 병기한다 |
| 추정 항목 | 입력에서 명시적으로 언급되지 않은 이해관계자는 이름 뒤에 `(추정·미확인)`을 붙인다 |
