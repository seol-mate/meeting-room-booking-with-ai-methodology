# 4-DN-21-O2 코드 정의서

> 시스템 전반에서 사용하는 공통코드(열거형 코드값)를 정의한다. 코드 그룹 단위로 관리하며, DB 공통코드 테이블 및 Backend Enum 클래스의 기준이 된다.

> **[작성 안내]** `project.framework`가 `NuriAF`이면 프레임워크 공통코드(언어·타임존·메뉴형태·권한레벨·UI테마 등
> 1800~1910번대 코드 그룹)는 Flyway 마이그레이션으로 자동 적재된다(`paths.nuriaf_docs/dev-guide/18-flyway-마이그레이션.md`).
> 이 문서에는 **업무 도메인 코드만** 정의하고 프레임워크 코드를 중복 기재하지 않는다(품질 게이트 dn-21.P8).
> `NuriAF`가 아니면 이 안내는 해당 없다.

> **[작성 안내]** 공통코드 관리 방식 — `NuriAF`는 `DB 테이블 (프레임워크 naf_code)`로 고정. `eGov`·`none`은 공통 개발규칙(`4-DN-21-O3`) §6의 선택 기준으로 정한다. 혼용이면 그룹별 방식을 §2 표의 `관리 방식` 열에 적는다. **[고도화]·[유지보수]** 편입 코드의 그룹이 셋 중 어느 것도 아니면(제약 없는 문자열 컬럼에 값 목록이 주석으로만 있는 경우 등) 그 그룹의 `관리 방식`에 관찰값(예: `문자열 상수 (Enum 아님)`)을 그대로 적고 근거(파일·마이그레이션)를 `설명`에 남긴다 — 코드가 정본이므로 방식을 바꾸어 적지 않는다

## 4. USER_ROLE — 사용자 역할

> 코드값은 사이트맵(`4-DN-31-O1`) §3 「접근 권한 코드」 표와 같다. `ALL`은 화면 접근 권한 표기용이며 `Reserver.role` 컬럼에는 저장하지 않는다(`USER`, `ROOM_MANAGER`만 저장).

| 코드값 | 코드명 | 설명 | 관련 요구사항 |
|--------|--------|------|--------------|
| USER | 예약자(일반 직원) | 로그인 후 예약 현황 조회·예약·내 예약 취소. `Reserver.role` 기본값 | REQ-F-001, REQ-F-005 |
| ROOM_MANAGER | 회의실 관리 담당자 | 회의실 관리, 전체 예약 조회, 다른 사람 예약 취소 | REQ-F-006, REQ-F-007, REQ-F-008 |
| ALL | 인증 불필요 | 로그인 없이 접근(로그인·가입 화면). 저장 값 아님 | REQ-F-001 |
